# WinterMMORPG ❄
เกม RPG พิกเซลอาร์ตธีมปีศาจ เลือด ฤดูหนาว แบบหลายผู้เล่น (HTML5 + เซิร์ฟเวอร์ Node.js)

## โครงสร้าง
- `docs/` หน้าเกม (ขึ้น GitHub Pages ได้: Settings > Pages > Deploy from a branch > โฟลเดอร์ `/docs`)
- `server.js` เซิร์ฟเวอร์เกม (Node 16 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ)
- `data/balance.json` **ตารางบาลานซ์ทั้งเกม** (แก้แล้วมีผลทันที ดูด้านล่าง)
- `saves/` บัญชี โปรไฟล์ผู้เล่น และค่าหัว (สำรองได้ด้วยการก๊อปโฟลเดอร์นี้)

## รันเซิร์ฟเวอร์
    node server.js
ฟังที่ `ws://localhost:8080` (เปลี่ยนพอร์ตด้วย `PORT=9000 node server.js`) เปิด http://localhost:8080 เล่นผ่านเครื่องตัวเองได้เลย

## ให้คนอื่นเข้าผ่าน GitHub Pages
หน้า GitHub Pages เป็น https ต้องต่อด้วย `wss://` วิธีง่ายสุด:

    cloudflared tunnel --url http://localhost:8080

แล้วให้ผู้เล่นใส่ `wss://xxxx.trycloudflare.com` ในช่อง "ที่อยู่เซิร์ฟเวอร์" หน้า log in (ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่)

## ปรับบาลานซ์ (buff/nerf, เศรษฐกิจ, เลเวลลิ่ง) โดยไม่ต้องอัปโหลดเกมใหม่
แก้ `data/balance.json` แล้วเซฟ เซิร์ฟเวอร์โหลดซ้ำเองภายในประมาณ 2 วินาทีและส่งให้ผู้เล่นที่ออนไลน์ทันที (ผู้เล่นไม่ต้องรีเฟรช) ถ้าไฟล์มี JSON ผิด เซิร์ฟเวอร์จะแจ้ง error และใช้ค่าเดิมต่อ
- `hero.<w|k|h|e>.hp / spd / atk` ตัวคูณเลือด ความเร็ว พลังโจมตี ของแต่ละตัวละคร
- `hero.<..>.s[0..2]` ตัวคูณของสกิล 1/2/3: `d` ดาเมจ `c` คูลดาวน์ `m` มานา
- `xp.base` EXP ที่ต้องใช้ต่อเลเวล (เลเวล × ค่านี้) และ `xp.mul` ตัวคูณ EXP ที่ได้จากมอนสเตอร์
- `econ.*` ทองจากมอนสเตอร์ (`gold`) ราคาโรงเตี๊ยม/ฝึก/เปลี่ยนตัว/ยา สต็อกยาสูงสุด อัตราขาย และเปอร์เซ็นต์ทองที่เสียตอนตาย
- `mon.*` ความแรงมอนสเตอร์ตามระยะ/ตามวัน และตารางมอนสเตอร์ 4 ชนิด (`mon.st`)
- `items` ไอเทมทั้งหมด (ชื่อ คำอธิบาย ราคา หมวด ค่าสถานะ passive) `quests` เควสทั้งหมด `dg` ดันเจี้ยน
- `pvp.dmg` ตัวคูณดาเมจ PvP และ `cap.*` เพดานของระบบตรวจดาเมจ
การเปลี่ยนกลไกสกิลจริงๆ (ไม่ใช่แค่ตัวเลข) ต้องแก้โค้ดในโฟลเดอร์ `docs/` แล้วอัปโหลดใหม่

## ระบบที่เซิร์ฟเวอร์ตัดสิน (กันโกง)
เงิน EXP เลเวล แต้มสกิล ไอเทม ยา เควส และตัวละครที่ใช้ เป็นข้อมูลบนเซิร์ฟเวอร์ ผู้เล่นแก้ฝั่งเครื่องตัวเองไม่ได้ผล (ค่าจะถูกเซิร์ฟเวอร์เขียนทับ)
- ซื้อ/ขาย/พักโรงเตี๊ยม/ฝึก ต้องอยู่ในอาคารนั้นจริง (เซิร์ฟเวอร์ตรวจตำแหน่ง) เปลี่ยนตัวละครต้องอยู่ใกล้โบสถ์ รับเควสที่กิลด์หรือบ้านชาวบ้าน ส่งของ/คุ้มกันต้องถึงที่หมายจริง
- รางวัลมอนสเตอร์ ดันเจี้ยน PvP ค่าหัว การตาย และการแลกเปลี่ยน คำนวณและโอนที่เซิร์ฟเวอร์
- ดาเมจต่อครั้งถูกจำกัดตามค่าสถานะที่เซิร์ฟเวอร์รู้ (เลเวล ไอเทม ตัวละคร) และจำกัดจำนวนครั้งต่อวินาที PvP ตรวจเงื่อนไขทั้งสองฝั่ง (เปิด PvP ทั้งคู่ นอกเมือง ระยะไม่เกิน 450)
- บัญชีเก่าที่เคยเซฟไว้จะถูกแปลงเป็นโปรไฟล์บนเซิร์ฟเวอร์อัตโนมัติตอนเข้าเกมครั้งแรก

## ข้อจำกัด
- เลือด มานา ตำแหน่ง และคูลดาวน์ ยังคำนวณฝั่งผู้เล่น (โกงเป็นอมตะหรือวาร์ปได้) เซิร์ฟเวอร์ไม่ได้จำลองการต่อสู้ทั้งหมด เหมาะกับเซิร์ฟเวอร์เพื่อนฝูง
- ภายในอาคารไม่มีมอนสเตอร์ ดันเจี้ยนและโลกภายนอกคำนวณที่เซิร์ฟเวอร์

ค่าใหม่ใน `data/balance.json` (แก้สดได้เหมือนเดิม):
- `mon.arm` = `[เริ่มหนาที่ z, ความหนาต่อ z, เริ่มหนาแรงที่ z, ตัวคูณกำลังสอง, เริ่มบวกคงที่ที่ z, ค่าบวกคงที่ต่อ z]` เส้นโค้งเกราะตามระยะจากเมือง (z = ระยะ/700)
- `mon.leash` = `{n, boss, wb}` ระยะ (px) ที่ถูกลากแล้วกลับจุดเกิด: มอนสเตอร์ทั่วไป / บอสกลางคืน / บอสโลก
- `loot` โอกาสรางวัลบอส: `leg` `legPer` `legMax` (เลเจนด์ = leg + legPer×เลเวลดัน สูงสุด legMax) `norm` `small` `cashGold` `cashXp` `baseGold` `baseXp`
- `wb.<pharaoh|titan>` บอสประจำไบโอม: ตำแหน่ง `x,y` เลือด `hp` เกราะ `ar` ดาเมจ `d` สกิล `bs` รายการดรอป `pool` เวลาเกิดใหม่ `respawn` (วินาที)
- `dg.<id>` ฟิลด์ใหม่: `mon` (ดัชนีชนิดมอนสเตอร์ใน `mon.st`) `ar` เกราะบอส `sm` ลูกสมุน
- `hero.<d|n|g|p>` ฮีโร่ใหม่ และ `hero.<h>.cap` ตัวคูณเพดานดาเมจของระบบตรวจโกงเฉพาะตัว (สกิลที่ตีเป็น % ของ Max HP หรือหมัดหนัก)
- ไอเทมที่มีช่องที่ 8 = `1` ใน `items` คือ "ดรอปอย่างเดียว" ไม่ขายในร้าน
