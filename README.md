# WinterMMORPG ❄
เกม RPG พิกเซลอาร์ตธีมปีศาจ เลือด ฤดูหนาว แบบหลายผู้เล่น (HTML5 + เซิร์ฟเวอร์ Node.js)

## โครงสร้าง
- `docs/` หน้าเกม (ขึ้น GitHub Pages ได้: Settings > Pages > Deploy from a branch > โฟลเดอร์ `/docs`)
- `server.js` เซิร์ฟเวอร์เกม (Node 16 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจ) เก็บบัญชี/เซฟ/ค่าหัวในโฟลเดอร์ `saves/`

## รันเซิร์ฟเวอร์บนคอมของคุณ
    node server.js
เซิร์ฟเวอร์ฟังที่ `ws://localhost:8080` (เปลี่ยนพอร์ตด้วย `PORT=9000 node server.js`) เปิด http://localhost:8080 เล่นผ่านเครื่องตัวเองได้เลย

## ให้คนอื่นเข้าผ่าน GitHub Pages
หน้า GitHub Pages เป็น https เบราว์เซอร์จึงยอมต่อได้เฉพาะ `wss://` (หรือ `ws://localhost` บนเครื่องคุณเอง) วิธีง่ายสุดคือเปิดอุโมงค์ฟรี:

    cloudflared tunnel --url http://localhost:8080

จะได้ลิงก์ `https://xxxx.trycloudflare.com` ให้ผู้เล่นพิมพ์ในหน้า log in ช่อง "ที่อยู่เซิร์ฟเวอร์" เป็น `wss://xxxx.trycloudflare.com` (ลิงก์เปลี่ยนทุกครั้งที่เปิดใหม่ ถ้าต้องการลิงก์ถาวรใช้ Cloudflare Tunnel แบบมีโดเมน หรือเปิดพอร์ตที่เราเตอร์ + ใส่ใบรับรอง TLS)
ถ้าเซิร์ฟเวอร์ไม่ได้เปิด หน้า log in จะขึ้น "เซิร์ฟเวอร์ยังไม่เปิด" และแสดงปิงเมื่อเชื่อมต่อได้

## สิ่งที่มีในเวอร์ชันนี้
บัญชี/รหัสผ่าน (scrypt) เซฟบนเซิร์ฟเวอร์ • เห็นผู้เล่นอื่นพร้อมชื่อ เลเวล หลอด HP/MP บนหัว • หน้ารายชื่อผู้เล่น (เลเวล ไอเทม ปิง) • ปิงเซิร์ฟเวอร์ • เวลากลางวัน/กลางคืนใช้ร่วมกัน • ปุ่ม PvP นอกเมือง (เมืองปลอดภัย) • สนามประลอง 1v1/3v3 • ค่าหัวและบอร์ดค่าหัวที่กิลด์ • ตายแล้วเสียทอง 20% และค่าหัว • ปาร์ตี้ (หัวหน้าเข้าดันเจี้ยน สมาชิกตามเข้า, แชร์ EXP/ทองในรัศมี 300) • แลกเปลี่ยนไอเทม/เงิน • เห็นการโจมตี/สกิล/ออร่าของผู้เล่นอื่น • แชทรวม • มอนสเตอร์ร่วมกัน (ฆ่า/ช่วยฆ่าแชร์ EXP+ทองในรัศมี 450)

## ข้อจำกัดที่ควรรู้
- มอนสเตอร์ทั้งโลกภายนอกและดันเจี้ยนคำนวณที่เซิร์ฟเวอร์ ดันเจี้ยนแยกห้องตามหัวหน้าปาร์ตี้ (สมาชิกในห้องเดียวกันเห็นมอนสเตอร์ชุดเดียวกัน) ภายในอาคารไม่มีมอนสเตอร์
- ยังไม่มี: การตรวจดาเมจ/ไอเทมของผู้เล่นฝั่งเซิร์ฟเวอร์
- ฝั่งผู้เล่นเป็นผู้ตัดสินดาเมจ/เงิน/ไอเทมของตัวเอง เหมาะกับเซิร์ฟเวอร์เพื่อนฝูง ไม่ป้องกันการโกงจริงจัง
